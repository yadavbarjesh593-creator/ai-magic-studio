AI MAGIC STUDIO — STARTER PROJECT

Included:
- Flutter starter app UI
- Dark purple theme
- Home, Effects, Projects, Profile tabs
- Gallery photo picker
- Placeholder dialogs for AI/video features

IMPORTANT:
This is a starter UI, not a complete AI editor. AI generation, background removal,
video rendering/export, accounts, cloud saving, payments and ads are not connected.

To build (requires Flutter SDK on a computer or a supported cloud build environment):
1. Create a Flutter project: flutter create ai_magic_studio
2. Replace its lib/main.dart with the supplied lib/main.dart
3. Replace/add pubspec.yaml with the supplied pubspec.yaml
4. Run: flutter pub get
5. Run: flutter build apk --release

For Android-only users:
A phone browser alone cannot compile this Flutter project into an APK.
You can keep the source files on your phone, then use a compatible cloud build
service or a computer later. Do not upload private photos/API keys to unknown services.
